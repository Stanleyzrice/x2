---
name: listing-images
description: 复用完整来源，必要编辑或采用干净原图，经X2导入上传及指纹审阅。
---

仅用于当前X2项目，沿用[上架](../../../skills/listing/SKILL.md)及[修改规则](../../../skills/listing/references/editing.md)。详细参数、长图、尺寸表、复用和失败处理见[已审图片流程](references/reviewed-images.md)。

默认：完整来源准备 → 实际看图 → 必要的 OpenAI Image（图像编辑）／`clean-original`（已审干净原图）→ X2导入上传 → 最终逐图与指纹审阅。Gemini（模型检查）及 `processed` 不是默认路径。

1. 先查已有稿、完整来源、审图、上传、在售及结果未决记录，保留人工值，只续缺项，不重复建稿或盲目重跑prepare／make／import。缺完整来源的单稿才用 `listing make --ids <稿号> --prepare-only`，再读 `listing reviewed-images-preview --id <稿号>`；准备成功不等于图片完成。
2. 完整核对源主图、详情图及全部已选 SKU（货源规格）映射，缺原文件用 `image save`。记录来源URL、角色、源及采用文件SHA256（文件指纹）、采用／过滤理由。真实已看且两个SHA、处理内容、当前款式规格适用性未变的证据可复用，不机械逐张重开；首次、新增、改变或有疑点的图才重新实际查看及必要对照。主图不能代替详情来源，不截断有效内容；同店上传记录由X2正式流程复用。
3. 后加简体说明用已授权OpenAI Image转台湾繁体；产地、厂名地址、供货联系区块局部移除，保留有效介绍。Logo（标志）、商标、真实实物／印花／包装本体及其文字不改，不换款或生成买家收不到的版本。材质工艺按事实，供应商示意不冒充实拍或实测；删字不能消除真实选品冲突。
4. 无待处理文字或地区区块、符合要求且款式规格对应的图，实审后用 `clean-original` 原文件，不重画。首次采用或修改的编辑图须查看真实输出并必要对照源图、所选SKU，保存处理SHA和证据；相同SHA已审处理图符合第2条才复用。生成成功不等于审阅通过；失败、未返回或仍有问题时留待核对，不用未处理图顶替，不伪造通过。
5. 已审文件经 `listing reviewed-images` 验源、导入上传，再用 `listing make --ids <稿号> --image-mode reviewed` 续做；完整参数和指纹见参考流程。沿用本店现有水印，未配置不新增。长图保全有效内容；尺寸表仅用已核源数值与明确单位，经 `chart-render`、`size-chart` 核图保存，不推算未知单位。
6. 字段齐备后 `listing review-preview`，完整核验当前唯一图片ID（编号）、角色、全SKU映射及指纹；有效看图证据按第2条复用，新增／改变／疑点部分重看。文案变化重审文案并以 `listing review` 绑定当前key，不能声称旧审阅直接有效；完整逐图结论不得漏项或伪造。发布仍经原授权、首次试单、写入确认及读回；未知先查询、不重发，分别报告准备、上传、审阅和在售结果。
7. 同稿的准备、导入上传、文案、审阅和发布依次完成读回，上传过程中不改稿。跨稿本地准备可并行，共享浏览器的切店、导航、刷新、上传和发布由同一执行者单队列串行，不在他稿上传中操作。工具失败先修X2正式能力，未恢复则报告未完成，不旁路网站接口、内部函数、缓存或业务库。

已审图片导入仅适用于未建商品稿；已上架补图走 `listing edit-preview`、`listing edit` 和原值保护。

`original`（原图）／`processed`（既有模型处理）仅人明确选用，不自动降级；原图不称已转换。不推广个别批次的尺寸、SKU或竞品特批，经营参数沿用现行规则及明确授权。
