# 定价与组合流程

## 参数与口径

ni1206、cheeroutdoor 统一沿用用户之前提供的 Excel「蝦皮定價計算器」日常定价公式。当前参数由本文件维护：

```json
{
  "fx": 4.8,
  "feeRate": 0.16,
  "freightPerKgRmb": 10,
  "labelFeeRmb": 1.5,
  "minMargin": 0.2,
  "maxMargin": 0.3
}
```

汇率单位为 TWD/RMB；头程为人民币/kg；贴单费为人民币/单。国内运费按实际商品另计，不能把某款地垫的国内运费扩展为全店默认值。

毛利率分母为扣平台费后的到手金额。目标是 20%–30%；旧的 15%–20% 区间和 25% 加每件人民币 8 元门槛不叠加。不采用 Excel 的直播目标或券后 12% 提示作为日常上品标准。

2026-11-11 本轮用户明确：以单套毛利率20%–30%作为定价目标；合购节省运费后毛利率可高于30%，不因上限强行加运费或调高估重。仍核对实际可下单组合不亏损且不低于20%。批发起订量与代发起购分开核实：只有当前货源明确展示单套代发条件及代发价时，才按该模式核价；保留原始批发MOQ，不能仅凭一件代发布尔值改为1。包邮代发价不再次叠加国内运费。

2026-11-17 用户新授权的当前通用默认：市场比价优先参考，不再把逐件取得可靠市场数据作为放行硬门槛。优先复用可用样本、只补必要缺项；遇登录、反爬或样本不足以代表主流等情况，不反复等待。市场均价／主流区间可保留未知或局限；来源、成本及卖家优惠已核清，且单件20%–30%毛利、真实规格、供货、图片、物流、规格上限等现行硬条件满足时，可按成本模型继续选品及上架流程，不再逐批要求竞品豁免。这源于本次新授权，不是外扩旧批次特例；不放宽其他选品或发布门槛。

## 单品核价

1. 读取本文件的当前参数；`listing pricing --shop <店>` 读取已保存的计算输入。如有差异，核对是否为用户新调整，不把旧运行配置当作新规则。
2. 参数确定后，`listing pricing-set --shop <店> --template '<完整参数 JSON>'` 保存运行输入。工具不决定使用哪组经营参数。
3. `listing quote --shop <店> --link <链接> --weight <保守估重> --freight <保守国内运费>` 报价，注明估计项。若单独试算，用 `listing price-preview`，六项参数都显式传入。
4. 快速上架直接复用现成的可比样本和有效核价。没有可用样本的商品立即进入第 5 条。有可靠市场依据时，将均价、中位数及主流价带与现行模板反推的单件20%–30%毛利整数售价区间对照：有交集时优先在交集内、主流附近，结合已核品质差异和店铺定位选价；成本目标价带整体高于可靠市场主流时，暂不选该单卖方案；整体低于市场时，核对可比性及影响成本结论的资料，属实可按目标内的竞争性价格选品。
5. 市场资料不足或暂不可取得时，保留未知／局限，按上述新默认核对成本及其他硬条件后继续，不等待逐件比价通过。优先考虑目标毛利区间内较有竞争力的可行尾9整数价，无可用尾9时选其他可行整数；须经代码复核，不机械顶30%，也不降低20%。选价仍满足现行单卖、起购及其他门槛，不把低价优先当作转化定律。若改固定套装或组合，须先有明确授权，再核对实际同件数、购买条件及每个可成交搭配。来源、成本、卖家优惠、真实规格或履约等硬条件未核清仍待核对；不能把市场未知标成比价通过，也不能删除或忽略已核实的不利价格证据来套用未知策略。

## 类目可比均价与市场位置

1. 类目均价指每件商品的可比样本均价，不是混合大类所有标价。优先复用已有同款或同用途、相近材质、同规格、同件数及同购买条件的可用样本，按这些条件分组，只补必要缺项，不为每个SKU重采整批。不能把小尺寸、配件、不同材质或不同件数的最低价套给目标SKU；实际起购及成套条件须保留，不能仅除以件数就抹去购买门槛。
2. 统一价格、优惠和运费口径：记录对应SKU的当前可购买价、件数、优惠资格与门槛、买家承担运费，明确统计是商品价还是到手总价。仅使用可核实、实际可取得的优惠；无法统一的价格分别列示，不混算均价。卖家承担优惠及物流等成本仍按本文件模板计入利润，不能与买家支付口径混淆或漏算。
3. 按店铺、商品及规格识别重复样本，同一卖家同款同规格的重复链接或重复采集不重复计权。引流错规格、仅定制报价、不可实际购买及其他异常样本须核实并记录排除原因；保留排除记录，不能为抬高均价而只删低价。每组记录样本链接、对应规格与件数、采样时间、原始数量、去重及排除理由、有效数量和实际价格口径。
4. 能统计时由工具计算有效样本的算术均价，同时查看中位数和主流价带，保存输入与结果。这是可比报价样本统计，不冒称全市场实际成交均价；没有销量依据不伪造销量加权。样本少、分布离散、优惠／运费不明或遇登录／反爬时记录局限，只补必要资料，不反复等待；不足以代表主流时不强算市场区间，市场项保留未知，可按成本模型及其他硬条件继续。缺数不补零，不用引流价代表市场，也不把均价当统一售价或机械上限；不写固定分位阈值，不只挑高价样本制造可行区间。
5. 可靠市场证据存在时按上节三种价格关系判断；不能把两个方向的无交集一律排除，也不能借市场未知策略绕过已知价格冲突。结合已核商品／品质差异、店铺定位、运费和起购条件评估竞争力；可靠成本优势可评估，整体高于可靠主流的方案仍暂不选。市场价格比较不等于转化率或销量预测；无实际数据不编数、不宣称低价必然高转化，市场不足时也不宣称已比价通过。

市场统计与成本区间的正式只读计算见[市场核价操作](market-pricing.md)。取整、数量和优惠金额由代码统一处理；将多件报价除以件数只是单位换算，不能据此认为一件可取得多件优惠。选择最终价格后仍按真实数量、卖家优惠和平台起购条件复核整单；本流程不自动调整在售商品价格。

## 组合与发货门槛

1. 按用户要求，指定商品可设置券后商品金额满 NT$199 的发货条件；不是所有商品统一设置此门槛。
   2026-11-04 本次 cheeroutdoor 已上架的69款明确采用订单商品金额合计满 NT$199 出货，可与本店其他商品合并凑单；金额不含运费。可低于199独立下单的商品标题写「滿199出貨」，本批全部商品描述写明订单合计条件。P002既有两件起送仍保留，不因购物车凑满199而取消其货源起购条件。商品页提醒不等于平台已设置金额拦单，须如实区分。
2. 单件不适合单卖时，可设计固定套装、同款多件或相关商品组合。先增加组合件数，让组合同时满足门槛与毛利目标，不能只抬高到门槛价格。
3. 调用 `listing order-preview`，传逐规格售价、件数、进价、重量、整单国内运费、卖家承担优惠和 `--minimumTwd 199`。无门槛场景传 0；无卖家优惠须明确传 0，未知就留空。
4. 读取 `profitRmb`、`margin`、`minimumMet`、`withinTarget` 和缺失项。整单人民币利润不得为负；缺数据、未达门槛或不满足目标的上品方案不通过。计算工具不返回发布或发货许可。
5. 多个货源的国内运费须合计。相同价、成本、优惠和购买条件的规格共用核算结果；其余规格单件均已达到下限，且合购无额外优惠、整单承运及费用已确认不会超过各单件结果之和时，可保存该上下界依据直接覆盖组合。组合会触发额外优惠、运费涨档、额外收费或不同起购条件时，仅补算受影响的组合。
6. 固定套装必须核对实际供货和件数；使用平台起购限制时须读回确认 checkout 条件。不能只在标题写“满199”而仍允许亏损单件成交。
7. KT 地垫是经营机制参考，当前平台设置须单独核对；未验证前，不宣称门槛已由平台执行。
