# 定价与组合流程

## 参数与口径

ni1206、cheeroutdoor 统一沿用用户之前提供的 Excel「蝦皮定價計算器」日常定价公式。当前参数由本文件维护：

```json
{
  "fx": 4.8,
  "feeRate": 0.16,
  "freightPerKgRmb": 10,
  "labelFeeRmb": 1.5,
  "minMargin": 0.2,
  "maxMargin": 0.3
}
```

汇率单位为 TWD/RMB；头程为人民币/kg；贴单费为人民币/单。国内运费按实际商品另计，不能把某款地垫的国内运费扩展为全店默认值。

毛利率分母为扣平台费后的到手金额。目标是 20%–30%；旧的 15%–20% 区间和 25% 加每件人民币 8 元门槛不叠加。不采用 Excel 的直播目标或券后 12% 提示作为日常上品标准。

## 单品核价

1. 读取本文件的当前参数；`listing pricing --shop <店>` 读取已保存的计算输入。如有差异，核对是否为用户新调整，不把旧运行配置当作新规则。
2. 参数确定后，`listing pricing-set --shop <店> --template '<完整参数 JSON>'` 保存运行输入。工具不决定使用哪组经营参数。
3. `listing quote --shop <店> --link <链接> --weight <保守估重> --freight <保守国内运费>` 报价，注明估计项。若单独试算，用 `listing price-preview`，六项参数都显式传入。
4. 按 Excel 公式反推整数售价区间；优先选择区间内尾 9，取整后重新核算。没有可用尾 9 时可选区间内整数；没有区间内整数时不擅自放宽目标。
5. 缺进货成本、计费重量、国内运费等关键数据，不通过核价。比较台湾同类成交价后再决定是否保留候选。

## 组合与发货门槛

1. 按用户要求，指定商品可设置券后商品金额满 NT$199 的发货条件；不是所有商品统一设置此门槛。
2. 单件不适合单卖时，可设计固定套装、同款多件或相关商品组合。先增加组合件数，让组合同时满足门槛与毛利目标，不能只抬高到门槛价格。
3. 调用 `listing order-preview`，传逐规格售价、件数、进价、重量、整单国内运费、卖家承担优惠和 `--minimumTwd 199`。无门槛场景传 0；无卖家优惠须明确传 0，未知就留空。
4. 读取 `profitRmb`、`margin`、`minimumMet`、`withinTarget` 和缺失项。整单人民币利润不得为负；缺数据、未达门槛或不满足目标的上品方案不通过。计算工具不返回发布或发货许可。
5. 多个货源的国内运费须合计；只有实际能共用的头程、贴单等费用才能共用。不得以某个组合的利润代替其他可成交搭配的核算。
6. 固定套装必须核对实际供货和件数；使用平台起购限制时须读回确认 checkout 条件。不能只在标题写“满199”而仍允许亏损单件成交。
7. KT 地垫是经营机制参考，当前平台设置须单独核对；未验证前，不宣称门槛已由平台执行。

## 决定与发布

按已确认的成本口径，后续只放行人民币不亏的商品及组合。最终方案由用户审核；本流程本身不授权改动在售价格、优惠活动、采购或发布。费用、优惠或组合条件变化后重新核价。
