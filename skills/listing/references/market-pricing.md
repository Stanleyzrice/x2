# 市场价格与成本模板对照

本文件说明正式计算入口，样本选择、毛利目标及选价决策只遵循[定价流程](pricing.md)。工具只统计显式输入并试算，不自动认定样本可比，不采集竞品、不保存店铺参数、不改在售价格或授权发布。

市场比价是优先参考项。优先复用适用的本地比较组；仅市场数据不足、登录或读取受限时不反复等待，成本及其他硬条件达标可按成本模型继续，市场均价或主流区间保留未知。已知可靠价格冲突仍须处理，不能把成本路径当成绕过冲突的办法。

## 先形成一组真正可比的样本

1. 按当前商品的用途、材质、规格、销售单位和购买条件分组。先复用X2已有资料，一组可服务符合条件的多个款式或SKU（规格）；只有必要差异才补读，不逐款重复查询。保留链接、规格、采样时间及适用范围，市场或条件发生实质变化才复核；不同尺寸不能无依据套同一报价。
2. 每条样本明确 `sampleId`、`sourceUrl`、`observedAt`、`paidTwd`、`units`。`paidTwd` 是已核优惠后、不含买家运费的商品总额，`units` 是其中相同销售单位的数量；一套是销售单位时，不能擅自再拆成零件。实际成交价与可购买报价须在证据中区别，不把报价统计冒充真实成交统计。
3. 数量归一仅用于计算，仍须核对优惠资格和最低购买数量。买家运费和到手总价另作竞争力核对，不与商品价混算；本店卖家优惠、头程、国内运费等继续按现行成本模板处理。
4. 同一来源商品/规格用稳定的 `sampleId` 去重。错规格、无法实际购买等排除项提供 `excludeReason`，保留原始输入；价格未知填 `null`，不能填0。不能为了提高均价任意排除有效低价样本。
5. 有依据时选出主流参考组 `referenceSampleIds` 并给 `referenceReason`，工具据此形成参考区间；不把极端最小/最大值自动当主流，不只挑高价样本制造交集。没有依据就保留参考区间未知并走成本路径，不为了凑主流组反复查找或编造数据。

## 正式只读计算

先读取 `listing pricing --shop <店>`，与规则中的当前六项参数核对；规则与运行值不一致按主流程处理。将确认后的完整模板及实际成本显式传入：

```sh
node x2.ts listing market-price-preview \
  --template '<当前完整六项参数JSON>' \
  --comparison-key '<商品稿/规格/材质/销售单位及购买条件>' \
  --cost-rmb '<每销售单位进价>' --weight-kg '<单位计费重量kg>' \
  --freight-rmb '<本次整单国内运费>' --units '<本次下单单位数>' \
  --seller-discount-twd '<本店整单承担优惠，确认无优惠填0>' \
  --market-samples - \
  --reference-sample-ids '["<已核主流样本ID>"]' \
  --reference-reason '<本次可比性与参考组依据>' --json < '<市场样本.json>'
```

命令是参数模板，不可直接使用占位内容。`market-samples` 为上述样本对象的JSON数组；排除理由可选。数据不足可不传主流组，工具仍能报告已知样本统计，但不会伪造主流区间或可发布结论。`--price-twd` 可另外传入已拟定的单位标价，复核其利润。参数及返回字段以 `--help` 和当前工具为准。

没有市场数据时可直接复用已有有效成本核价，或调用 `listing calculator-preview`；已调用市场工具而返回 `NO_MARKET_DATA`、`REFERENCE_GROUP_REQUIRED` 时，可复用返回的 `pricing.rangeTwd`、`pricing.suggestedPriceTwd` 及利润结果。它们是成本试算，市场候选为空不等于商品被禁止发布。按当前目标区间优先考虑有竞争力的可行尾9，不机械取毛利上限；复核真实数量、卖家优惠和其他硬条件后继续。成本或卖家优惠未知仍须补齐，不能当0；不为相同有效输入重复计算。

工具按可比销售单位等权计算均价、中位数、最低和最高价，并报告原始、有效、未知、排除及去重数量。相同样本ID但价格或件数冲突时明确拒绝，先核清而非静默选一个。

成本计算复用现有 `calculatePricing`，不另建公式。尤其注意：市场样本是优惠后单位商品价，成本模板的 `rangeTwd` 是已加回本店卖家优惠的单位标价区间；工具先按本店整单优惠及数量转换口径，再取整数交集、给出候选及各自利润和毛利。卖家优惠未知时不能当0计算。

## 看结果而非只看均价

| 成本目标价带相对主流参考 | 如何继续 |
|---|---|
| 相交 | 在真实交集内结合均价、中位数、已核品质及店铺定位选价，优先合适的尾9整数；再核真实起购及整单 |
| 整体高于 | 说明达到目标毛利的最低价已高于主流，暂不选该单卖方案；不能抬价或降低毛利门槛硬上 |
| 整体低于 | 可能有成本优势，复核货源、品质、费用和可比性后按目标毛利内价格继续评估；不自动排除，也不追高到超出单件目标毛利 |
| 仅市场或主流组未知 | 市场待补如实标注；成本、卖家优惠及其他硬条件齐备且目标毛利达标，可按成本模型继续，无需另申请市场豁免 |
| 关键成本或卖家优惠未知 | 保留具体硬缺项，补足后重新核价；不能用空值或统计成功冒充成本核价完成 |

候选及比较状态均为数值事实，不是入选/发布许可或转化率预测；仍执行单卖、起购、供货、品类、图片和履约规则。选价后用 `order-preview` 复核真实可成交数量、卖家优惠及门槛；需要保存到未建稿时用 `pricing-inputs` 提供明确价格和依据。在售商品调价另走对应授权与 `edit-preview`、`edit`。

写回未建稿的 `pricing-inputs` 每条须给真实 `skuId`、已核 `costRmb`、`chargeableWeightKg` 和所选整数 `priceTwd`，在 `sourceEvidence` 中附市场比较文件及选价理由，沿用既有真实成本与采购依据。不能把市场均价写成进货成本，也不能用备选 `source-update --prices` 代填零售价；后者的字段是来源采购价。已有人工确定的售价或成本不擅自覆盖，冲突先保留并说明；写回后复核结果及最终审阅指纹，不把试算候选当作已保存价格。

每件交付保留：所复用比较组及样本时间、已有有效/排除样本、已知均价/中位数/参考区间、成本目标区间、最终售价、利润、选择理由和市场待补项。市场待补与发布状态分开记录；未来取得有效新资料或用户要求时再复核，改价另走授权，不生成隐性的后台采集或自动改价任务。不能声称未知市场已比价通过，或某个候选价保证最高转化率。
