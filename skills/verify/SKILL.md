---

运行 `pnpm verify` 检查类型、lint（静态检查）、架构、单测和网页构建。

- 数据库事务有改动时加跑 `pnpm test:integration`。验证现有数据只在临时库写入。
- 连接器读取有改动时，用已登记的只读工具实测。回包样本入库前去除个人信息。
- 写入引擎或采购写入状态有改动时，按对应 TLA+（状态模型）文件中的命令检查。真实写入须有明确约定的单件试跑授权。

## 网页验证

1. 运行 `node x2.ts web --scratch --port 5199` 启动数据库副本。终端会显示临时库名。修改界面后重新启动以加载新构建。
2. 用 `node x2.ts browsers` 查看浏览器，用 `node x2.ts page list` 查页编号。多个浏览器时给截图命令加 `--browser <名字或编号>`。
3. 对有视觉改动的页面，在修改前后分别截图到临时目录。对照截图，检查变更位置、控制台异常和失败请求。网络尚未稳定时重截。

   ```sh
   node x2.ts shot --url 'http://127.0.0.1:5199/#<页编号>' --out "<临时目录>/x2-page.png"
   ```

4. 验证操作时向临时服务发对应请求并检查结果。缺少示例组件时，用临时库地址设置 `X2_DATABASE_URL`，再用 `page create` 和 `page push` 准备页面。
5. 用 Ctrl-C 停止服务并清理临时库。报告通过的检查和受环境限制的未验证项。
