# 一轮怎么分

- 一轮给每家店各选一批，两家店的货不一样：`listing list` 看两家店已有的货源，不加重复的。
- 按方向分：cheeroutdoor 做居家（浴室、收纳、玄关、厨房、寝具）；ni1206 做户外露营、旅行、车用、宠物，偏养猫和宠物小设备。它卖得好的是卡通硅藻泥地垫，买家多半养猫；宠物小设备例 洗澡架、窗户猫吊床，台湾卖 NT$300–500、卖家不多、1688 是 ¥10–20 的爆款，有价格空间。车用、伞、牵绳、宠物碗这类台湾本地大批进货、主流价低，赢不了。
- 每个在用的策略分一份名额，起步每个 20 个左右。
- 几个选品 agent 同时跑时按类目分开（别都看宠物出行、车用收纳）。知虾每小时 200 次是共用的：每个 agent 一小时用 60 次左右，一个词看够就换。
- 上架 14 天看曝光、点击，30 天看订单、毛利，再调策略：好的多分名额，差的停掉（`selection strategy-set`）。
