读者是选品的 agent。命令在 x2 仓库根目录运行：`node bin/x2.ts <命令>`（下面简写成 `x2`），加 `--json` 读结果。策略、规矩、选品理由怎么记在 [docs/listing.md](../../../docs/listing.md)「策略」。跟运营说起商品稿用「简称（店铺）」。

## 一轮怎么分

- 一轮给每家店各选一批，两家店的货不一样（`x2 listing list` 看两家店已有的货源，不加重复的）。两家店按方向分：cheeroutdoor 做居家（浴室、收纳、玄关、厨房、寝具）；ni1206 做户外露营、旅行、车用、宠物（接住它现有的买家）。每个在用的策略分一份名额（起步每个 20 个左右），能开 subagent 就一个策略一个 `listing-select`（给它店、策略、名额、别的策略在找的方向，免得撞货），主对话不装候选的细节。
- 上架 14 天看曝光、点击，30 天看订单、毛利，再调策略：好的多分名额，差的停掉（`x2 strategy set … --why`）。

## 步骤

1. **`x2 strategy list`、`x2 rule list`**：照在用的策略的「选品方法」找，照在用的选品规矩筛。规矩、策略要改，先跟运营说，用 `x2 rule add / retire`、`x2 strategy set … --why` 记下来，不只留在会话里。
2. **找词、找竞品（知虾）**：`x2 zhixia hot-words --path <类目路径>` 拿热搜词（`searchVal` 是全站搜索量），`x2 zhixia hot-word-items --word <词 id> --path <类目路径>` 看词下竞品（按 30 天销量排），`competition`、`price-line` 看竞争和价格带。算集中度、价格带前剔掉 NT$0、NT$1 的「客製化 / 客訂」下单链接，价格用 30 天实际均价。爆品近亲的种子从店里卖得好的来：`x2 shopee performance --shop <店> --period past30days --start … --end …`。知虾限流（每次隔 6–10 秒、每小时 200 次），一个词看够就换下一个。
3. **找 1688 货源**：优先用竞品的主图以图搜：`x2 zhixia similar-1688 --image <图片地址>`。对造型明确的硬货（置物架、毛巾杆、浴室五金、书本保险箱、靠垫）很准；对透明的、布艺、纯文字的图没用，`.webp` 图会报错（换一张）。1688 搜索（`x2 1688 search`）少用，一次一个：搜得密会跳滑块（退出码 3，请运营在 cheeroutdoor 的浏览器里拉一下）。
4. **报价**：每个候选 `x2 listing quote <1688 链接> --shop <店>`。看售价区间、规格数、重量（估的会写出来）、服务（一件代发、48 小时发货）、起订量、问题。一个一个报，别连着刷。
5. **筛**（选品规矩是准，下面是做法）：
   - 规格超过 50 个的不选；不是一件代发、48 小时发货、起订量 1 的不选。
   - 售价要比台湾同类卖得好的便宜或差不多：我们的售价下限大约 NT$85–90，台湾主流价低于 NT$120 的小件赢不了；能赢的是台湾卖 NT$150–400、1688 进价 ¥10–25 的较大件。
   - 不碰 IP、品牌（书封、印花上的角色名、店名水印都看一眼），不碰要认证的（电器、带电池、食品、化妆品、婴幼儿、医疗）和要尺码表的（衣服、鞋）。
   - 只上店铺允许的类目：居家生活里的大多可以；运动健身、母婴、保健这类 Shopee 推荐过去会不在范围（做商品稿时变成待补充、要运营定）。
   - 1688 的重量看着不对的记下来（例 每个尺寸都填 0.9–1 kg、或小于 20 克）：做商品稿时 agent 会往重了估。1688 不给每个规格的销量，没法按销量挑规格。
6. **加成商品稿**：`x2 listing add <店> <1688 链接> --strategy <名字> --why "为什么选它（一两句）" --evidence "依据"`。依据写数据：台湾热搜词和搜索量、竞品（店名、售价、30 天销量、是不是本地现货）、竞争和价格带、1688 月销、报价（售价区间、规格数、重量）。理由不一样的分开加。要注意的（规格名看不出区别、图上有简体字或可疑的 IP、某个规格建议去掉）写进依据末尾，写文案、审稿的人会看。
7. **回报**：每个策略加了哪些（简称或 1688 标题、售价区间、为什么选），放弃了哪些、为什么（规格太多、太便宜、没有 48 小时发货……），这一轮学到的（哪类货赢不了、哪种找法不灵）。学到的要改规矩或策略的，提给运营定。

之后照 listing skill：`x2 listing make` → 估重量 → 写文案 → 批准 → `x2 run`。
