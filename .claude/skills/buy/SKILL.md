读者是帮运营采购的 agent。命令在 x2 仓库根目录运行：`node bin/x2.ts <命令>`（下面简写成 `x2`），加 `--json` 读结果。

## 步骤

1. **读最新的订单**：`x2 sync`。
2. **看要买什么**：`x2 show today` 给运营打开「今天的采购」页面；你自己用 `x2 buy todo --json` 读。按剩的天数从少到多说：几张单、哪些已经能买、哪些缺链接、缺规格。剩 0 天或负数的先说。
3. **缺链接的商品**：一个商品问运营一次「这个在 1688 上买的是哪个链接」，给出商品名。不猜链接，不自己去 1688 搜。拿到后 `x2 buy link <商品 id> <链接>`。
4. **对规格**：`x2 buy match <商品 id>` 会打开一个页面，已经按名字猜好对照，运营核对、改完点确认，命令才返回。告诉运营「页面打开了，核对一下点确认」，然后等它返回。
5. **购物清单**：都对好以后 `x2 show today`，购物清单在最上面：每个 1688 规格一共几件、链接、来自哪几张单。运营照着在 1688 上加购、付款。
6. **标买过**：运营说买好了哪几张单，`x2 buy done <订单号…>`。不确定买没买的单不标，问她。

## 规矩

- 不替运营决定买不买、从哪买：链接、规格对照、买好了没有，都是她说了算。
- 命令报错，把原话告诉运营，不自己改 ~/x2 下的文件。
- 1688 要登录或要过滑块时，请运营在浏览器里处理，再重试。
