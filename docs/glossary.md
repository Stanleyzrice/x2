# 词

读者是写文档、写代码、在收件箱和 NocoDB 里写字的人和 agent。一个概念一个词，一个词只指一样东西。词从运营的话和站点上的字来，不自己造；新概念先在这里加一行再用。先例 lilto 的 `docs/glossary.md`。

## 店铺和站点

| 词 | 意思 | 不用 |
|---|---|---|
| 店铺 | Shopee 上的一家店。用账号名叫它：ni1206（Nydia's shop）、cheeroutdoor（新新家居日用好物賣場） | 用店铺 id、店名叫它 |
| 站点 | x2 读写的网站：Shopee、1688、知虾、chanboss | — |
| chanboss | 货代（c.chanboss.com）：收我们寄去的货，打包，寄到台湾；台湾有仓库（退件、取消的货上架在那，30 天内没用掉就被货代处理掉） | 仓老板、仓库 |
| 操作 | 站点能做的一件事，有名字：读的（`x2 shopee orders`）、写的（加购、预报） | 动作 |

## 循环

| 词 | 意思 | 不用 |
|---|---|---|
| 同步 | 把站点读进库，按「目标多新」决定读不读。知虾要读的类目和词也是同步 | 采集、观察、读取 |
| 镜像 | 同步来的表，人只看 | — |
| 检查 | x2 的代码：拿「怎样算做完」对一遍库，算出收件箱和 agent 要做的 | — |
| 收件箱 | 人要做的事，一件一行；条件不成立了自己关掉 | 待办、任务 |
| 处理好了 | 收件箱里 x2 看不到结果的事，人做完勾上，那一行关掉、不再开 | 完成、已处理 |
| 谁做 | 收件箱一行归谁：运营、采购、财务……，照「谁做」表填 | 负责人、角色 |
| 写入 | 做了一次写操作：先记意图，提交一次，读回来，记下结果 | 动作、回执 |
| 批准 | 人同意一批写入：在收件箱里勾「批准」 | 确认 |
| 结果未知 | 写入提交了，不知道站点做了没有。不重发，先读回来 | — |
| 库 | NAS 上的 Postgres，唯一的数据 | store |

## 订单

| 词 | 意思 | 不用 |
|---|---|---|
| 订单 | Shopee 的一张订单。chanboss 上同一个订单号的那张，是它在 chanboss 的进度 | 订单行、入仓单、仓库单、履约 |
| 订单号 | Shopee 的订单号，chanboss 用同一个 | 单号 |
| 平台状态 | 订单在 Shopee 上的状态：待出货、已出货、已完成、不成立…… | — |
| chanboss 状态 | 订单在 chanboss 上的状态：待处理、已预报、已到齐、已打包、已出库…… | 仓库状态 |
| 出货期限 | Shopee 要求最晚什么时候出货（chanboss 上叫「截止」） | 最晚出货、发货期限 |
| 快到期 | 离出货期限不到 N 天，还没「已打包」 | — |
| 采购账号 | 做采购的那一个 1688 账号：x2 只往它加购，别的账号只读 | — |
| 加购 | 把货加进采购账号的 1688 购物车：agent 准备，人批准 | — |
| 在外面买的 | 不是经 x2 加购、对采购单时对上的货（人直接在 1688 上买的） | — |
| 付款 | 人在 1688 购物车里付钱，付完说「我付好了」 | — |
| 采购单 | 1688 上付了款的订单 | 「要买什么的清单」（`x2 buy` 以前这么叫） |
| 对采购单 | 付款后，按 1688 规格把采购单对回加购：哪几张订单付了、寄到哪、快递单号、签收了没。每轮现算，不记账 | 认领、分配、预留 |
| 寄到我们这里 / 寄到 chanboss | 采购单的收货地址。决定怎么预报、要不要打包。我们这里 = 1688 的默认地址（东莞，收件人「1971张」） | 贴单、仓库拆 |
| 到货问题 | 打包时发现的错货、少件、坏了：人在 NocoDB 的表单里报，处理完勾「处理好了」 | 异常件、问题件（chanboss 的「问题」是问题单） |
| 预报 | 在 chanboss 上报这张订单的货怎么来：海快 + 无单号，或海快 + 快递单号 | — |
| 取消预报 | chanboss 上撤掉一次预报 | 撤预报 |
| 打包 | 寄到我们这里的货到齐以后：拆开，按订单分，贴拣货单，寄给 chanboss。也说人工分拣 | 分拣（chanboss 的「分拣中」是到台湾以后的另一步） |
| 拣货单 | chanboss 的「SKU 拣货单」：一张订单一张，人在 chanboss 上自己打 | — |
| 问题单 | chanboss 标了「问题」的订单 | 仓库问题、异常 |
| 台湾仓 | chanboss 在台湾的仓库：退件、取消的货上架在那，30 天内没给别的订单用掉就被货代处理掉 | — |
| 售后 | Shopee 上的退货、退款 | 案件 |
| 退件 | 退回 chanboss 的货 | — |

## 商品和货源

| 词 | 意思 | 不用 |
|---|---|---|
| 商品 | 店里的一个商品 | — |
| 规格 | 商品的一个规格（颜色、尺寸） | SKU、店铺规格、model |
| 货源 | 1688 上的一个商品 | offer、货源方案、货源链接（链接只是它的地址） |
| 1688 规格 | 货源下面的一个规格 | 源 SKU、源规格 |
| 选货源 | 给一个规格定货源和 1688 规格：agent 先找，找不到才问人 | 补货源、找货、对照 |
| 货源候选 | 选货源时 x2 找到的一个「货源 + 1688 规格」，人勾「用这个」 | — |
| 选品候选 | 选品时的一个产品方向 | 候选（单说容易和货源候选混）、选品库 |
| 商品稿 | 还没建到 Shopee 上的商品：标题、图、规格、价格…… | 草稿、刊登稿 |
| 核价 | 按货源价和店铺参数算利润、求售价 | — |
| 备货天数 | Shopee 商品要几天内出货；预购的才能设长 | — |
